# Frontier — 3D DCC Icon Suite

A comprehensive, production-grade icon collection designed specifically for 3D Computer Graphics, Digital Content Creation (DCC) software (such as Blender, Maya, Houdini, Cinema 4D, Unreal Engine, and 3ds Max), and WebGL/game pipeline tools.

The visual style is inspired by premium **3D Claymorphic / Stylized Matte Plastic** aesthetics (charcoal bodies `#1e2025`, warm marigold/amber accents `#f59e0b`, electric cyan `#38bdf8`, soft bevels, tactile reliefs, and studio lighting), paired with clean **2D Production Vector** equivalents.

## 🚀 Live HTML Preview Features

- **3D Clay Gallery**: Interactive cards with realistic mouse-following parallax 3D tilt.
- **2D Production View**: Clean, high-contrast monochrome line/solid icons for compact DCC toolbars.
- **Real-Time WebGL 3D Inspector**: Powered by Three.js with OrbitControls, studio key/fill/rim lighting, tactile roughness and metalness shaders, turntable rotation, and wireframe toggle.
- **Interactive DCC Workspaces**:
  - *UV Editor Workspace*: UV 0..1 coordinate grid with movable UV islands, checkerboard texture toggle, and packing animation.
  - *Physics Node Graph*: Real-time 2D canvas particle simulation driven by vortex and wind forcefields.
  - *3D Modelling Viewport*: Interactive polygon modeling HUD with component selection modes (1=Vertex, 2=Edge, 3=Face) and transform gizmo.
- **Reference Style Board**: Direct visual comparison with the 8 original reference images.
- **Export Capabilities**:
  - One-click SVG Code Copying
  - High-Resolution 1024×1024 PNG Rendering via Canvas
  - Full ZIP Archive Export (All 62 SVGs + JSON Manifest)
  - SVG Sprite Sheet Generator
  - React JSX and Vue 3 Component Generators
