# Frontier

## Projects

- [`Experimental/Terrain`](Experimental/Terrain/README.md): **Frontier Terrain**, a WebGPU terrain generator and texturing tool. It has a terrain layer stack with physically based erosion, a material layer stack driven by simulation maps, and a physically based viewport with a CDLOD terrain, a Hillaire 2020 atmosphere and analytic water. Run it with `node Experimental/Terrain/tools/serve.mjs`.
