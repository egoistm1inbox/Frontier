# Sun drawing proof font

DM Sans, SIL Open Font License 1.1; see `OFL.txt`.

Source: google/fonts Git blob `c672f98060af9b2c85fca704ebd5ad9a8717c1df` (`ofl/dmsans/DMSans[opsz,wght].ttf`). License blob: `4430b85ac62998e2edb914360f9ebdfe43f4deaa`.

`DMSans-Regular.ttf` is a static instance generated with fontTools `instantiateVariableFont(font, {'wght': 400, 'opsz': 14}, inplace=True)`. It is shared by the native drawing proof and independent SVG reference renderer to control font variation during comparison. The approved HTML also names DM Sans, but browser optical sizing, shaping and rasterization still require separate visual verification. This is not a claim that its complete typography has been ported.

`DMSans-Light.ttf` uses the same pinned source and license, instanced at weight 300 and optical size 48 for the full inspector's large reference metrics. Native sliders retain their existing ControlPanel font ownership and drawing code.
