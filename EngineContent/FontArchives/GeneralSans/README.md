# General Sans

General Sans is distributed by Indian Type Foundry through Fontshare (https://www.fontshare.com/fonts/general-sans)
under the ITF Free Font License and is not mirrored on a public Git host, so the files are not vendored here.

Drop the static faces (`GeneralSans-Light.ttf` … `GeneralSans-Bold.ttf`, plus `-Extralight` / `-Semibold` if wanted)
into this folder; `FontCodec` discovers them on the next start and the Fonts tab shows the family in slot 2.
