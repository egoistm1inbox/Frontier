Frontier App Launcher

One page that redirects to every HTML app in the repo — Alloy Studio and all the painting references. Each button says exactly which app it opens, so there is nothing to search for. Served from the repo root so PaintingSurface’s absolute /EngineContent/… fetches resolve.
