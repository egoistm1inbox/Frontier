Every pixel below came out of a real ImGui draw list, rasterised on the CPU and written to PNG by Exhibits/Workbench/Notes/NativeEntityNotes.cpp. Nothing here is a mock-up.

This one is a correction, not an addition. The shipped component is Inspectors.jsx:409, rendered from the shared Header() for every subject, with its boxes in the bundle's inlined .entity-notes rules. The native RecordNotes drew something else entirely: a chevron disclosure inside a rounded 18 px inset card, a letterspaced caps header and a 64 px field. None of that shape is in the reference.

And folders had no note at all. Of the fourteen branches in InspectorPanel::Record, thirteen called RecordNotes; the folder branch returned early without it. In the reference a folder is a group subject and goes through the same header as everything else, so it carries a note like anything else. It does now.
