# Automotive paint lab

Serve this directory and open `index.html` (session live preview: port 5188).

This is a live shader, not a PNG slideshow. Use **Move light**, drag the swatch to orbit, and adjust the flake/coat parameters. Native C++ reference images are below the canvas. The default diameter is 0.35 mm on a close-up 140 × 90 mm curved sample, deliberately making the individual flakes visible.

`Engine/Shaders/AutomotiveFlakePaint.slang` is compiled as both C++ and GLSL. The existing engine thin-film functions provide the optional pearl response. `shared.glsl` is generated by `Exhibits/Workbench/AutomotiveFlakes/RunProof.py`, not maintained independently.

- Native: 58,693 checks PASS in Release, Debug and ASan/UBSan.
- GLSL: actual WebGL 2 execution on Chromium / SwiftShader; 64 RGB probes agree with the native results to within 0.07% relative error.
- Density ranges from 0 to 16× and adds independently seeded flakes rather than brightness.
- Add up to eight flake-colour families, edit their start/end colours and relative shares, and remove unwanted families. Each flake keeps its assigned colour.
- The **Blue coat + RGB flakes** preset uses 4× density. Clearcoat tint is independently editable and is an artistic reflection/transmission tint, not a spectral dye model.
- The coat stays independent of flake orientation. No time-randomized or emissive glitter.
- Distance filtering uses a bounded, approximate population blend, not DB23 binomial glints.
- The sample is lit by two rectangular-source quadratures and diffuse ambient fill. No full HDR IBL/global-illumination claim.
- The new material is a standalone review implementation. Production Project-Zero bindings, sampling/PDF integration, Vulkan and Windows certification are not delivered here.

Details, measured stack and limitations: `Docs/AutomotiveFlakePaint.md`.

### Asset cache safety

The preview server sends `Cache-Control: no-store`. HTML loads a content-versioned `paint.js`, which requests a content-versioned shader with caching disabled. `RunProof.py` refreshes both cache keys automatically; after JavaScript-only edits run `python3 Exhibits/Workbench/AutomotiveFlakes/VersionAssets.py`. The browser regression test blocks both old unversioned asset URLs and still verifies compilation, all 64 probes, and the palette/density controls.
