The obstruction: a table, because the two numberings only look alike
  PASS  obstacle type 0 is an absence and stays one
  PASS  1 is a sphere at both ends, which is why the cast looks safe
  PASS  2 is a vertical cylinder, and the enum's 2 is a capsule — the table says cylinder
  PASS  and it stands on the floor rather than floating with a half-height of nothing
  PASS  3 lies along X, so it is admitted as its bounding box
  PASS  and says so, because a diverted plume is not a visible defect in itself

  PASS  🔴 4 is a deflector slab and the enum's 4 is a cylinder — the cast would have been silent here

  PASS  5 is a tyre ring at both ends
  PASS  but an upright ring cannot spin about axis 2, and the reading says so
  PASS  an obstacle type this build does not know is absent, not guessed
