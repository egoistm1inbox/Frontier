# SolidArc Set 3 plan — bounded partial cone–cone root chamfer

## Bounded next slice

Add the next mixed curved-edge chamfer route as a canonical coaxial cone–cone sector:

- accept one open non-reflex circular root chain shared by two native coaxial conical frusta;
- support the canonical half-turn and one general non-reflex sector with explicit radial endpoint caps;
- measure both cone endpoint pairs, common root frame, root radius, lower/upper heights, and cap positions;
- derive equal setbacks along both measured conical supports in the meridian;
- reconstruct exact retained lower cone, straight conical chamfer band, retained upper cone, axial caps, and radial endpoint-cap healing;
- require exact genus-zero topology, an analytic angular-fraction volume check, transactional source immutability, console dispatch, and visible proof.

## Explicit non-goals

Non-coaxial or oblique cone/cylinder or cone/cone supports, apex/zero-radius cones, arbitrary trimmed or reflex arcs,
branched or incomplete chains, mixed curved networks, corner patches, freeform supports, and general
intersection/trim/sew healing remain explicit refusals. This slice does not broaden the existing canonical complete or
partial cone–cylinder routes.
