# Icons

Native Project Zero editor icons, taken from the self-contained Project Zero Editor build
(`Experimental/ProjectZeroEditor/index.html` on Frontier-OLD `arena/bc062d35-frontier-old`), where they ship from
`EngineContent/Icons`. Slate-derived icons keep the notice that accompanies them there.

`editor-capsule.svg`, `editor-pane.svg` and `editor-hex-column.svg` are new, drawn in the same 256 px blue
isometric style for the primitives Project Zero does not have.
