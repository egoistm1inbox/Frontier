SolidArc, in your browser.

        
      

      

        This is the existing C++ SolidArc geometry, command interpreter and
        software rasterizer compiled to WebAssembly—not a replacement geometry
        mockup. It runs locally in a worker, without a CAD server.
      

      

        Orbit DragPan Right / middle-dragFit FSelect points / edges / faces / bodies 1–4Undo / redo Ctrl Z / Ctrl Shift ZSave native document Ctrl S
      

      

        Use Construct (Tab while the viewport is focused) for the native
        Reference, Sketch Draw, Solid and Surface catalogue. Drag the native
        gizmo to move, rotate or scale; Ctrl snaps and Escape cancels. Alt-drag
        always orbits. The Transform inspector has editable XYZ rows and reset
        chips. Select geometry in the viewport or outliner; Shift-click extends
        the selection. Live dimensions rebuild native geometry. Numeric pills
        support typing and horizontal dragging. Double-click an outliner row or
        document tab to rename it.
      

      

        The native kernel still has bounded operation support: unsupported
        intersections, fillets or face edits report a refusal in the command
        log. This web build does not certify general CAD correctness. .arc saves
        preserve native construction, not a flattened preview. Imported files
        are limited to 8 MB; up to four live documents. Camera/display
        preferences are session-only. OBJ export is tessellated, not STEP. Large
        native models can be slow with CPU rasterization.
