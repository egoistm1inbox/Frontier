Global Icon Registry

The authoritative index of every registry glyph. Each entry is Index · Name · Key · SVG. The C++ IconPackGlobal encoder reads the REGISTRY-MANIFEST block below — a stable, comment-delimited line-per-icon table (index | key | name) — and pulls each glyph's document from the matching <symbol id="key">. Indices are contiguous and reshuffle-safe: when new icons land the whole set is re-indexed 0..N-1, so the parser keys off key (stable) and treats index as the reshuffled slot of the moment.
