The Workplane

A workplane (also called a sketch plane, construction plane, or reference plane) is the flat 2D surface you draw a sketch on. You can't draw a line, arc, or circle "in mid-air" — every 2D element has to live on a plane. That plane fixes where in 3D space your 2D drawing sits and which way it faces. Extrude/revolve/sweep then lift that flat sketch into a solid.

One sentence: a workplane is an infinite flat sheet with an origin and an orientation — pick one, and your sketch tools snap onto it so everything you draw is coplanar and locatable.

Why you need one before drawing

Location

A 2D point (u, v) on the plane maps to a real 3D point. Without a plane, "x = 40" is ambiguous.

Orientation

The plane's normal is the direction "up out of the paper" — it's the direction an Extrude pushes.

Coplanarity

Everything you sketch shares one flat surface, so constraints (parallel, tangent, dimension) are solvable in 2D.

The three default planes (XY, XZ, YZ) are handed to you in every new document. Everything else is a plane you build from existing geometry.

The three planes you always start with

XY — Top

Horizontal. Looking straight down. Usually the default active plane. Normal = +Z.

XZ — Front

Vertical, facing you (front↔back). Normal = +Y (in a Y-up world).

YZ — Right

Vertical, side profile (left↔right). Normal = +X.

Axis convention differs per app (Y-up vs Z-up). Frontier's atmosphere profile is Y-up, so use Y-up here unless the modelling core says otherwise.

Ways to make a new workplane

Beyond the 3 defaults, you build a plane by referencing existing geometry. These are the standard construction methods (identical set across Fusion 360, SolidWorks, Onshape — only names differ):

MethodWhat you pickWhat it makes
Offset / Plane Point A plane/face + a distance A parallel copy shifted along the normal by that distance. The workhorse.
At Angle / Line Angle An edge/axis to pivot on + a plane + an angle A plane rotated about the edge — for chamfered/slanted faces.
Three Point Three points/vertices The unique plane through all three.
Mid Plane / Midplane Two parallel faces/planes A plane centred exactly between them (symmetry).
Tangent A cylindrical/curved face + a point or reference plane A flat plane touching the curve — to sketch onto a round body.
Point & Normal / Curve Point A point (origin) + a line/curve (normal) Plane through the point, perpendicular to the line/tangent — for sweeps along a path.
On a Face Any existing planar face of a solid Not a new plane — you just sketch directly on the model face.

The workflow it fits into

  1. Pick or build a workplane.
  2. Start a sketch on it — the view snaps flat to it, the sketch grid appears.
  3. Draw 2D geometry + add constraints/dimensions.
  4. Finish the sketch, then Extrude / Revolve / Sweep along (or about) the plane's normal.
  5. Sketch on a face of the new solid, or build another workplane, and repeat.
For Frontier specifically: you have no plane concept yet — this is greenfield. Minimum first cut = the 3 default planes + Offset + On-Face, each carrying an origin, a normal, and a grid. Everything else (Angle, 3-Point, Tangent…) is additive later. Keep the plane parametric (store the method + references, re-solve the transform) so it moves when its host geometry moves — matching your parametric-authoring direction.
