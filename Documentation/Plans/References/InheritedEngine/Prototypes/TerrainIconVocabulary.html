Terrain Icon Vocabulary

A node-graph icon set for a terrain erosion editor, drawn on a 0 0 160 160 canvas with a shared 3D material system — radial/linear gradient bodies, blur filters, grounding shadows, and specular highlights. Every <defs> entry is suffixed with the icon's unique id, so any number of icons coexist on one page without collisions. Each glyph shows what its node does to the heightfield, not just a generic label. Click a tile to copy its standalone SVG.
