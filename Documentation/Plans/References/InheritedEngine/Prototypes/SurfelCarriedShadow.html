Surfel-carried shadow — watch it in action

Left = Integrate: surfels fire sun rays and remember the answer (a running average — that's the temporal cache). Right = Shade: paints pixels by reading the surfels back, firing no rays. Toggle the old way to compare. A rock (occluder) casts a soft shadow on the floor.

Integrate — the cache filling up fires rays

Each surfel shoots 1 sun ray this frame; a blocked ray darkens its stored visibility, an open one brightens it. The value is a running average over frames → converges to soft.

Shade — the image you see reads cache

Every floor pixel finds its nearest surfels and reads their stored visibility — a lookup, not a ray. The soft edge comes for free from the averaged cache.
