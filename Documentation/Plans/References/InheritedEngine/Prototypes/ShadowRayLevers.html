Making the shadow ray cheaper — every lever

SunVisibility() fires N rays / pixel / frame. Green = exact (no quality change). Amber = quality dial. Blue = big win, big effort.

1 Any-hit early-out exact

Return the instant one triangle blocks the sun. No FarLimit tighten, no stack drain past the hit. Wins most on shadowed pixels — the costly ones.

biggest structural win · task #12

2 Clamp ray distance exact

Rays pass 1e4. Swap for the real sun / scene-bound distance so far boxes fail the test early. One constant.

cheapest to ship · one line

3 Drop near/far sort exact

Closest-hit sorts children near-first to tighten early. Any-hit needs no order — skip the LeftEntry≤RightEntry compare entirely.

rides on #1 · same walk

4 Keep origin epsilon sane exact

Current scale-relative nudge is correct. Shrinking it self-intersects: extra traversal and shadow acne. Don't touch — just don't regress it.

guard, not a gain
