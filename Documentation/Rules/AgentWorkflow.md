# Agent Workflow

Read `../../CLAUDE.md` from this directory and its four mandatory skills at session start.
Scope work to the approved plan. Inspect before editing; never silently replace inherited code.
Run relevant local checks before delivering, with visible results and honest blockers.
GitHub Actions need explicit approval, including workflow-triggering remote operations.
Keep work on the session branch. The user authorised committing and pushing this selective port.
No GitHub Actions may run.
Use the single tracker and planned folder ownership; no competing agent folders or reports.
Windows binaries are the default binary deliverable. Linux binaries require a request.
