# Evidence

Run relevant local checks before delivery. Present an image, graph, table, or concise report.
Retain reproducible results in `Exhibits/<ValidationName>/` with generating code and instructions.
Record command, prerequisites, tested revision, relevant uncommitted changes, configuration, and limitations.
Use expected-versus-observed results for numerical claims and actual captures for UI appearance claims.
Do not present browser mockups as native editor evidence or generated imagery as an application capture.
Do not invent measurements. Report failed, blocked, and unrun checks separately.
Windows binaries require a real Windows-target build; report whether they were actually run on Windows.
A Linux check is not verification of a Windows binary. No GitHub Actions without explicit approval.
